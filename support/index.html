Compatibility and product boundaries

兼容性与产品边界

  • Chrome 132 or later on macOS or Windows is required.
  • LoginFlip works on ordinary HTTP(S) sites that Chrome allows extensions to access. Chrome internal pages and the Chrome Web Store are protected.
  • LoginFlip switches snapshots in a cookie store; it is not an isolated multi-container browser.
  • Expired or revoked sessions, SSO, device verification, passkeys, and server-side security rules may require sign-in again.
  • LoginFlip handles applicable cookies and current-origin localStorage, not IndexedDB, sessionStorage, cross-origin iframe state, passwords, or passkeys.
  • 需要 macOS 或 Windows 上的 Chrome 132 或更高版本。
  • LoginFlip 支持 Chrome 允许扩展访问的普通 HTTP(S) 网站；Chrome 内部页面和 Chrome 应用商店属于保护页面。
  • LoginFlip 在一个 Cookie Store 中切换快照，不是隔离的多容器浏览器。
  • 登录过期或被撤销、SSO、设备验证、Passkey 和服务端安全规则仍可能要求重新登录。
  • LoginFlip 处理适用 Cookie 与当前 origin 的 localStorage，不处理 IndexedDB、sessionStorage、跨域 iframe 状态、密码或 Passkey。

Troubleshooting checklist

故障排查清单

A saved account asks me to sign in again

已保存账号要求重新登录

The website may have expired or revoked the server-side session. Choose “Relogin and update” for the saved account, sign in normally, then update it. LoginFlip cannot override website security decisions.

网站可能已让服务端会话过期或撤销。为该账号选择“重新登录并更新”，正常完成登录后再更新。LoginFlip 无法覆盖网站自身的安全决定。

A switch did not finish

切换没有完整完成

Keep the original tab on the same website and use the recovery action shown by LoginFlip. Avoid signing out manually before adding another account because a website may revoke the old session.

请让原标签页停留在同一网站，并使用 LoginFlip 显示的恢复操作。添加另一个账号前不要主动退出旧账号，网站可能因此撤销旧会话。

A shortcut does not work

快捷键不可用

Another app or extension may already use it. Open chrome://extensions/shortcuts and check the actual shortcut assigned to LoginFlip.

其他应用或扩展可能已经占用该组合键。打开 chrome://extensions/shortcuts，检查 LoginFlip 实际分配到的快捷键。

The current page is unsupported

当前页面不支持保存

Open an ordinary HTTP(S) website. Chrome internal pages, extension pages, browser settings, and the Chrome Web Store do not expose the required site storage to extensions.

请打开普通 HTTP(S) 网站。Chrome 内部页面、扩展页面、浏览器设置和 Chrome 应用商店不会向扩展开放所需的网站存储。

Report a product problem

报告产品问题

Email xinning000@gmail.com and include:

请发送邮件到 xinning000@gmail.com，并包含：

  • LoginFlip and Chrome versions;
  • macOS or Windows version and display scale;
  • regular or incognito mode;
  • exact reproduction steps using a dedicated test account;
  • expected result, actual result, visible error, and whether recovery was offered.
  • LoginFlip 和 Chrome 版本；
  • macOS 或 Windows 版本及显示缩放；
  • 普通窗口或无痕窗口；
  • 使用专用测试账号得到的准确复现步骤；
  • 预期结果、实际结果、可见错误，以及是否出现恢复入口。

Never send real cookies, localStorage dumps, exported backups, passwords, account identifiers, personal screenshots, or production credentials.不要发送真实 Cookie、localStorage 数据、导出备份、密码、账号标识、包含隐私的截图或生产凭据。
